# Inicial

- Membros: Pedro Anastácio Nascimento Silva, Maria Luiza Lunes da Silva, Kauê Costa Nascimento e Ícaro Clemtente da Silva

- Trilha: Academia

- Problema que o sistema resolve: O projeto tem como objetivo solucionar o uso excessivo de papel nas academias, especialmente no processo de organização e distribuição das fichas de treino. Atualmente, os instrutores precisam procurar as fichas de cada aluno, localizar seus respectivos treinos e entregar as folhas manualmente, o que necessita de tempo e gera gasto desnecessário de papel

Com a digitalização, busca-se reduzir o uso de papel e, consequentemente, a produção de resíduos, afim de contribuir para a preservação do meio ambiente. Além disso, a solução proporciona maior praticidade aos alunos, assim permitindo que acessem seus treinos de maneira rápida, fácil e eficiente, enquanto facilita o trabalho dos instrutores na organização e disponibilização dos exercícios
